Sign in

This page works directly with your GitHub repo. Paste a GitHub access token that only you have. It is kept in this browser and sent only to GitHub.

How to get a token (2 minutes, once)
  1. On GitHub, click your picture (top right), then Settings.
  2. At the bottom of the left menu, click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token. Name it "SponsorLive admin" and pick an expiry (90 days is sensible).
  4. Under Repository access, choose Only select repositories and pick sponsor-live-jobs.
  5. Under Permissions, set Actions, Contents and Issues to Read and write.
  6. Click Generate token, copy it and paste it above. Don't share it or save it anywhere public.

Site settings

Open site

Change the wording, colour and links on the public site. Saving publishes the change; it's live in about a minute.

Set up the suggestion and feedback form (once, about 5 minutes, no login needed for visitors)
  1. Go to forms.google.com and create a blank form called "Suggest a company".
  2. Add three questions, in this order: Company name (Short answer), Careers page link (Short answer) and Feedback (Paragraph). Leave all three not required, and in Settings make sure Collect email addresses is off.
  3. Click the ⋮ menu (top right), then Get pre-filled link. Type COMPANY, LINK and FEEDBACK in the three answers, click Get link, then Copy link. Paste it in the first box above.
  4. In the form's Responses tab, click Link to Sheets and create a new sheet.
  5. In that sheet: File, Share, Publish to web. Choose the responses tab and Comma-separated values (.csv), click Publish, and copy the link. Paste it in the second box above.
  6. Click Save and publish. The site's "Missing a company?" box now sends to your form, and every refresh reads the sheet.
